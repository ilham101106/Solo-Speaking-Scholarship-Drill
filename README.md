# 🎓 ScholarSpeak — Solo English Speaking & Scholarship Drill

A dedicated interactive solo practice web platform and 6-month roadmap designed to master **English Speaking** for **Study Abroad Scholarships** (LPDP, Chevening, AAS, Fulbright, Erasmus, etc.), college presentations, and academic defense.

🌐 **Live Demo:** Deployable on Vercel  
📱 **Mobile-Ready:** Optimized for smartphones and desktop browsers.

---

## 🚀 Key Features

1. **🎯 Scholarship Prompt Generator:**
   - Real scholarship interview questions (Elevator pitch, study choice, failure, future contribution).
   - Storytelling prompts formatted with the **STAR-L Method** (Situation, Task, Action, Result, Learning).
   - Solo 3-slide academic presentation pitches formatted with the **PREP Framework** (Point, Reason, Example, Point).
   - 60-second spontaneous impromptu drills.

2. **🎙️ Solo Voice Studio & Timer:**
   - In-browser voice recording via MediaRecorder API (zero external server lag).
   - Countdown / elapsed stopwatch tailored for each speaking exercise (60s, 2m, 3-4m).
   - Instant playback review to identify pauses and filler words.

3. **📊 Slide Blueprint Guide:**
   - Structured 3-slide ignite pitch template for academic presentations.
   - Built-in transitions and discourse markers.

4. **🗺️ Comprehensive 6-Month Roadmap:**
   - See [ROADMAP_SPEAKING_SCHOLARSHIP.md](./ROADMAP_SPEAKING_SCHOLARSHIP.md) for full weekly milestones and daily practice routines.

---

## 💻 Tech Stack
- Pure Vanilla HTML5, CSS3, JavaScript (ES6+).
- Web Audio & MediaRecorder API.
- Fully responsive design. Zero heavy build tools required.
